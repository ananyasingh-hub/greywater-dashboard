💧 Greywater Management System

Smart Water Quality Monitoring and Reuse Assessment

1. About the Project

The Greywater Management System is a web-based dashboard developed using Python and Streamlit.

The project aims to analyse greywater quality using machine learning and assess its potential suitability for different reuse purposes.

2. Project Objectives

- Analyse important greywater quality parameters.
- Explore and visualise greywater datasets.
- Predict water quality categories using machine learning.
- Assess potential suitability for different reuse applications.
- Support informed greywater management and reuse decisions.

3. Technologies Used

- Python
- Streamlit
- Pandas
- Machine Learning
- Data Visualisation

4. Dashboard Features

The dashboard includes five main sections:

1. Home: Project introduction, objectives and workflow.
2. Water Quality Input: Enter sample information with input validation.
3. Predictions: Display planned water quality and reuse suitability predictions.
4. Analytics: Explore the dataset, view statistical information and download CSV data.
5. About: Project information and objectives.

5. Project Dataset

The project uses "greywater_ml_features.csv" for greywater data analysis.

6. How to Run the Project

Install the required dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app_v2.py
